# Tavinh Cloud - Gerenciador de Máquinas Virtuais

Um aplicativo leve e gratuito para criar e gerenciar máquinas virtuais.

## 📥 Download

Baixe a versão mais recente do [TavinhCloud.exe](https://github.com/seu-usuario/tavinh-cloud/releases/latest)

## 🚀 Características

- ✅ Interface gráfica intuitiva
- ✅ Configuração personalizável de CPU, RAM e disco
- ✅ Suporte a múltiplos sistemas operacionais
- ✅ Opção para ISOs customizadas
- ✅ Leve e rápido

## 🛠️ Como Usar

1. Baixe o `TavinhCloud.exe`
2. Execute o aplicativo
3. Configure sua máquina virtual
4. Clique em "Criar Máquina Virtual"

## 📋 Requisitos

- Windows 7 ou superior
- Java 11 ou superior
- 2GB de RAM mínima
- 500MB de espaço livre
